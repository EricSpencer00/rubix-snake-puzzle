04What the formal models cover

This repository explores a formal description of the puzzle. It does not prove Aylett's 24-piece count; the models and their current limits are listed here.

Coq / Rocq

Integer-grid model

Defines rotations and a repeated-cell check. Two claims remain unproved; this does not establish the full count.
TLA+

Small-state specification

A draft for checking shorter chains. This page does not report a completed model-checking run or a 24-piece proof.
Python

Python search

Enumerates paths, treating any repeated lattice cell as a collision. This is a different check from the builder's prism-overlap test.
